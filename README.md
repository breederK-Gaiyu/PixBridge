# PixBridge v1.5

🖼️ **达芬奇剪贴板图片自动导入工具**

一个专为 DaVinci Resolve (达芬奇调色) 设计的剪贴板图片自动导入工具，让你从浏览器或任何应用复制的图片无缝导入到达芬奇媒体池。

## ✨ 主要功能

- 🔄 **实时剪贴板监控** - 自动检测剪贴板中的图片变化
- 🌐 **浏览器图片支持** - 支持从网页直接右键复制图片
- 🚫 **智能去重机制** - 使用图片哈希避免重复导入同一张图片
- 📁 **自动分类管理** - 自动导入到达芬奇的 `Clipboard_Assets` 媒体文件夹
- 💾 **本地自动保存** - 同时保存副本到本地预设文件夹
- 🎨 **优雅的深色界面** - 采用现代化 UI 设计，与达芬奇风格一致
- 📊 **实时状态监控** - 显示导入统计、缓存记录和运行日志
- ⚡ **高效线程安全** - 多线程处理，不阻塞界面
- 🗑️ **缓存管理** - 可手动清除缓存，允许重新导入之前的图片

## 🎯 使用场景

- 从网页复制参考图片快速导入达芬奇
- 截图后直接粘贴到达芬奇项目
- 批量管理剪贴板图片素材
- 设计师与剪辑师的素材快速传递

## 📋 系统要求

- **操作系统**: macOS (使用 AppKit 剪贴板监控)
- **Python**: 3.8+
- **达芬奇版本**: DaVinci Resolve 17.0+ (含免费版)

## 🚀 使用方法

### 方法一：直接运行（推荐测试）

```bash
python3 PixBridge_v1.5.py
```

### 方法二：安装到达芬奇脚本目录

1. 复制脚本到达芬奇脚本目录：

```bash
cp PixBridge_v1.5.py "/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Edit/"
```

2. 在达芬奇中：
   - 打开 **工作区 (Workspace)** → **脚本 (Scripts)**
   - 找到并点击 `PixBridge_v1.5`

### 使用步骤

1. **启动达芬奇** 并打开一个项目
2. **运行 PixBridge** 脚本
3. **设置保存路径**（可选，默认为 `~/Downloads/Clipboard_Assets`）
4. **点击"开启实时监听"**
5. **从任何地方复制图片**（Cmd+C 或右键复制）- 浏览器、Finder、截图工具等
6. **自动导入完成** - 图片会自动出现在达芬奇的 `Clipboard_Assets` 文件夹中

**重要提示**：
- ✅ 只有在**新的复制操作**（Cmd+C 或右键复制）后才会触发导入
- ✅ 相同的图片不会被重复导入（基于图片内容哈希）
- 🗑️ 如需重新导入相同图片，点击"清除缓存"按钮

## 🚫 智能去重机制

PixBridge v1.5 实现了基于图片内容哈希的去重机制：

- **工作原理**：计算每张图片的 MD5 哈希值，防止重复导入
- **自动检测**：相同内容的图片只会导入一次
- **缓存管理**：缓存记录在会话期间保持，关闭程序后清空
- **手动清除**：点击"清除缓存"按钮可重置去重记录

**示例**：
1. 第一次复制某张图片 → ✅ 成功导入
2. 再次复制同一张图片 → ℹ️ 跳过（已导入过）
3. 点击"清除缓存" → 🗑️ 缓存已清除
4. 再次复制该图片 → ✅ 成功导入

## 🔧 配置说明

### 媒体文件夹名称

脚本默认创建/使用的媒体文件夹名称为 `Clipboard_Assets`，可在代码中修改：

```python
MEDIA_FOLDER_NAME = "Clipboard_Assets"  # 第 38 行
```

### 默认保存路径

默认保存到用户下载文件夹，可以修改：

```python
self.save_dir = os.path.expanduser("~/Downloads/Clipboard_Assets")  # 第 178 行
```

或在界面中动态修改。

## ⚠️ 故障排查

### 问题 1：无法连接到达芬奇

**解决方案**:
1. 确保达芬奇正在运行
2. 确保已打开一个项目
3. 检查达芬奇偏好设置 → 系统 → 启用"外部脚本"

### 问题 2：图片保存成功但未导入达芬奇

**可能原因**:
- 达芬奇 API 权限问题
- 项目媒体池被锁定
- 文件路径包含特殊字符

**解决方案**:
- 重启达芬奇
- 检查媒体池是否处于可编辑状态

### 问题 3：剪贴板监控不工作

**可能原因**:
- 仅支持 macOS 系统
- AppKit 模块未安装

**解决方案**:
```bash
# 确保在 macOS 上运行
# PyObjC 应该是 macOS Python 自带的
pip3 install pyobjc-framework-Cocoa
```

### 问题 4：启动后不停地导入剪贴板内容

**解决方案**：
- ✅ v1.5 已修复此问题
- 现在只有在**新的复制操作**（Cmd+C 或右键复制）后才会导入
- 启动时剪贴板中已存在的内容不会被导入

### 问题 5：相同图片重复导入

**解决方案**：
- ✅ v1.5 已实现智能去重
- 相同内容的图片只会导入一次
- 如需重新导入，点击"清除缓存"按钮
